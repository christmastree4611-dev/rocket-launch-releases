# Rocket Launch

Download **[Rocket Launch for Windows x64](https://github.com/christmastree4611-dev/rocket-launch-releases/releases/latest/download/RocketLaunch.exe)**. Open the launcher, select **Install**, then **Play**. Rocket Launch verifies each game release and keeps your player data in a separate directory.

## Use your existing Rocket Cars account

1. In Rocket Launch, open **Account** and choose **Continue with Google** with the Google account you already use for Rocket Cars.
2. Your Rocket Cars username and friends appear automatically. To enable email sign-in on this same account, enter a new password under **Email sign-in** and choose **Set password**.
3. On first play, select your previous save location when prompted. If you kept the game elsewhere, use **Library settings → Import from a Saved folder** and select its `RocketCars/Saved` directory.

Local guest play is available. Career data, controls, garage settings, and replays are stored on each PC. Friends, account names, and competitive ratings use the shared Rocket Cars backend.
